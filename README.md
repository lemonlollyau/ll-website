# LemonLolly website

Static marketing site for LemonLolly (Adelaide marketing studio).
Hosted on Vercel, source of truth on GitHub. Push to `main` = publish.

- `index.html` — home page
- `klaviyo-shopify.html` — Klaviyo for Shopify landing page (/klaviyo-shopify). Self-contained styles; forms post to Formspree
- `agency-check.html` — free agency health check (/agency-check). Self-contained; scoring engine is the block between ENGINE-START/END, unlock form posts to Formspree
- `hire-or-agency.html` — hire a marketer vs agency cost calculator (/hire-or-agency). Self-contained; engine between ENGINE-START/END, report form posts to Formspree
- `favicon.svg` — site icon
- `vercel.json` — hosting config (clean URLs)
- `robots.txt`, `sitemap.xml` — SEO

Built from the LemonLolly Home design in Cowork.
